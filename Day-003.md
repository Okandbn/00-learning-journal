## Permission Basics

```text
r = read    = 4
w = write   = 2
x = execute = 1
```

Permissions are divided into:

```text
owner | group | others
```

Example:

```text
rwxr-xr--
```

Becomes:

```text
rwx | r-x | r--
 7  |  5  |  4
```

So the octal permission is:

```text
754
```

## Common Permissions

```text
600 = rw-------   → owner can read and write
640 = rw-r-----   → owner can read/write, group can read
644 = rw-r--r--   → owner can read/write, others can read
660 = rw-rw----   → owner and group can read/write
755 = rwxr-xr-x   → owner full access, others read/execute
770 = rwxrwx---   → owner and group full access
```

## chmod

`chmod` changes file or directory permissions.

```bash
chmod 660 project.txt
```

This produces:

```text
rw- | rw- | ---
```

## chown

`chown` changes ownership information.

Change only the owner:

```bash
sudo chown okan project.txt
```

Change only the group:

```bash
sudo chown :developers project.txt
```

Change both:

```bash
sudo chown okan:developers project.txt
```

## UID and GID

```text
UID = User ID
GID = Group ID
```

Check user information:

```bash
id
```

Check another user:

```bash
id labuser
```

## Users and Groups

Create a group:

```bash
sudo groupadd developers
```

Create a user with a home directory:

```bash
sudo useradd -m labuser
```

Add a user to a group:

```bash
sudo usermod -aG developers labuser
```

Here:

```text
-a = append
-G = supplementary groups
```

So `-aG` means:

```text
Add the user to a new group without removing existing group memberships.
```

## sudo

`sudo` runs a command with elevated privileges.

Example:

```bash
sudo chown okan:developers project.txt
```

Run a command as another user:

```bash
sudo -u labuser touch test.txt
```

## Least Privilege

Use only the minimum permissions required for a task.

Avoid unnecessary use of:

```text
sudo
root
chmod 777
```

## umask

`umask` affects the default permissions of newly created files and directories.

Check current value:

```bash
umask
```

Example:

```text
0022
```

With `umask 0022`, new files are usually:

```text
644 = rw-r--r--
```

New directories are usually:

```text
755 = rwxr-xr-x
```

## Permission Denied Troubleshooting

Example:

```bash
chmod 000 file1.txt
cat file1.txt
```

Result:

```text
Permission denied
```

Check permissions:

```bash
ls -l file1.txt
```

Restore permissions:

```bash
chmod 644 file1.txt
```

A file may also be inaccessible if the user does not have permission to traverse its parent directories.

## Shared Directory

Example shared directory:

```text
/srv/team-share
```

Set owner and group:

```bash
sudo chown okan:developers /srv/team-share
```

Set permissions:

```bash
sudo chmod 770 /srv/team-share
```

This means:

```text
owner  = rwx
group  = rwx
others = ---
```

## setgid

Enable setgid on a shared directory:

```bash
sudo chmod 2770 /srv/team-share
```

Check:

```bash
ls -ld /srv/team-share
```

Example:

```text
drwxrws---
```

The `s` in the group permission means `setgid` is active.

When `setgid` is enabled, new files inherit the parent directory's group.

Example:

```text
Parent directory group = developers
User creating file      = labuser
```

New file:

```text
owner = labuser
group = developers
```

## Technical Terms

1. **Permission:** A rule that determines what actions a user can perform on a file or directory.

2. **Owner:** The user who owns a file or directory.

3. **Group:** A collection of users that can share permissions on files and directories.

4. **Read Permission:** Permission that allows a user to view the contents of a file.

5. **Write Permission:** Permission that allows a user to modify a file or directory.

6. **Execute Permission:** Permission that allows a user to run a file or traverse a directory.

7. **UID:** A unique numeric identifier assigned to a Linux user.

8. **GID:** A unique numeric identifier assigned to a Linux group.

9. **Umask:** A setting that controls which permissions are removed from newly created files and directories.

10. **Setgid:** A special permission that causes new files in a directory to inherit the directory's group ownership.
