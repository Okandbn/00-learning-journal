## Technical Terms
1. **Repository:** A directory where Git tracks files and their history.
2. **Commit:** A saved snapshot of changes in a Git repository.
3. **Branch:** A separate line of development in a Git repository.
4. **Staging Area:** A place where changes are prepared before a commit.
5. **Working Directory:** The folder where you create and modify your project files.
6. **Git:** A version control system used to track changes in files.
7. **Version Control:** A system that records changes to files over time.
8. **Markdown:** A lightweight markup language used to format plain text.
9. **Untracked File:** A file that Git sees but is not yet tracking.
10.**GitHub:** A platform for hosting and collaborating on Git repositories.
